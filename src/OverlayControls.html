GPC -

Launch

Command line changes take effect on Relaunch.

Preset file : (none)

Load reads a .gpc file and relaunches the emulator with its command line.

Bezel & window size

Aspect is locked to the bezel; changing one updates the other.

Look (brightness, scanlines, tint)
Screen fit

Moves/scales the emulator picture inside the bezel opening (offsets in bezel-image pixels).

Moves/scales the picture itself inside the opening, independent of the screen fit above. Needs Enhanced rendering ; the picture is clipped to the opening.

GPU rendering & screen shape
Glass (GPU)

Port of the TRS80 project's glass shader. Scale / offset are "auto" (fit the screen) until you move them.

Scene lighting & reflections (GPU)
Post processing (GPU)

Brightness, scanlines, vignette and phosphor tint (Look section) are applied by the GPU renderer while it is on.

Power rect

Click = CRT power animation. Double-click = animation + pause (off) / cold restart (on) of the emulator. Shift + double-click quits the app. Line / dot / fade timing and brightness below drive the animation.

Frame & overlay

Stripping the menu disables its Alt shortcuts. Use the hotkey to restore it.

Hotkeys

Format: Ctrl+Alt+F (needs at least one of Ctrl / Alt / Shift / Win). The last five only work while the emulator / overlay has the focus; blank disables one. The mouse wheel over the bezel changes the screen brightness.
